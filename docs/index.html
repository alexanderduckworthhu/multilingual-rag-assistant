WHO Guidance QA: Multilingual RAG

Document QA over WHO topic guidance with EN/FR indexing, nine answer languages, passage-level citations, and refusal when retrieval is weak.

This is a static project page hosted on GitHub Pages. Prefer the hosted live demo when it is available; if Streamlit/Render is asleep or unreachable, use this page and run the app locally from the repository.

Live demo (Streamlit) ↗ Code on GitHub ↗ Portfolio ↗

Status: Portfolio demo, not an official WHO product

Challenge & trade-offs

  • multilingual-e5-small for offline multilingual retrieval into a shared EN/FR index; Chroma for inspectable local indexes.
  • Trust stack: distance gate → closed-context prompt → cited answer → verifiable source passages.

Impact

  • Precision@5 = 0.65 · MRR = 0.938 on a golden-query eval set.
  • Nine answer languages with an extractive fallback that works without an API key.
